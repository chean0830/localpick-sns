# 화면 설계 · 사이트맵

## 사이트맵

```
로컬픽 홈 (index.html)
├─ 회원: 로그인(login.html) · 회원가입(signup.html)
├─ 피드: 전체 / 팔로우 / 우리동네 / 이벤트 탭 (index.html)
│   ├─ 게시글 상세(post.html)
│   └─ 게시글 작성·수정(write.html)
├─ 가게: 가게 찾기(stores.html) · 가게 프로필(store.html) · 가게 등록(mypage.html#stores, 사장님)
├─ 이벤트·쿠폰: 진행 중 이벤트(events.html) · 이벤트 등록(write.html 이벤트 유형, 사장님)
├─ 검색: 통합 검색 · 해시태그 결과(search.html)
├─ 마이페이지(mypage.html): 프로필 · 내 게시글 · 팔로우 가게 · 내 쿠폰함 · 홍보 통계(사장님)
└─ 관리자(admin.html): 가게 승인 · 게시글 관리
```

## 주요 화면

| 화면 | 파일 | 구성 |
|---|---|---|
| 메인 피드 | `index.html` | 통합 검색, 피드 탭, 게시글 카드(유형 배지·사진·좋아요·댓글), 진행 중 이벤트 위젯, 인기 해시태그 |
| 가게 프로필 | `store.html` | 팔로우 버튼, 게시글·팔로워·이벤트 수, 게시글/이벤트/가게 정보 탭 |
| 게시글 작성 | `write.html` | 유형 선택(사장님만 홍보·이벤트), 가게 선택, 사진 최대 5장, 해시태그, 쿠폰 설정 |
| 마이페이지 | `mypage.html` | 내 게시글, 팔로우 가게, 쿠폰함(사용 처리), 내 가게·홍보 통계, 가게 등록 |
