# 요구사항 정의서 · 기능 정의서

## 요구사항 정의서

| 요구사항 ID | 구분 | 요구사항명 | 상세 내용 | 우선순위 |
|---|---|---|---|---|
| REQ-001 | 회원 | 회원가입/로그인 | 이메일 회원가입·로그인, 일반회원/사장님 회원 구분 | 상 |
| REQ-002 | 회원 | 마이페이지 | 프로필 수정, 내 게시글·팔로우 가게·보유 쿠폰 조회 | 중 |
| REQ-003 | 가게 | 가게 등록/관리 | 사장님 회원이 업종·주소·영업시간·소개를 등록·수정 | 상 |
| REQ-004 | 피드 | 게시글 작성 | 사진(최대 5장)·본문·해시태그로 일반/홍보/이벤트 글 작성 | 상 |
| REQ-005 | 피드 | 피드 조회 | 팔로우한 가게 피드와 우리동네(지역) 최신 피드 제공 | 상 |
| REQ-006 | 소통 | 좋아요/댓글 | 게시글 좋아요, 댓글 작성·삭제 | 중 |
| REQ-007 | 소통 | 가게 팔로우 | 가게를 단골(팔로우)로 등록·해제 | 중 |
| REQ-008 | 마케팅 | 이벤트·쿠폰 | 기간·수량 한정 쿠폰 이벤트 발행, 회원 다운로드·사용 | 상 |
| REQ-009 | 검색 | 통합 검색 | 가게명·업종·해시태그·지역으로 검색 | 중 |
| REQ-010 | 관리 | 관리자 | 게시글 블라인드 처리, 가게 등록 승인 | 하 |
| REQ-011 | 비기능 | 반응형·보안 | PC/모바일 반응형, 비밀번호 BCrypt 암호화, 세션 인증 | 상 |

## 기능 정의서

| 기능 ID | 메뉴 | 기능명 | 기능 설명 | API | 관련 요구사항 |
|---|---|---|---|---|---|
| F-01 | 회원 | 회원가입 | 이메일 중복 확인, 회원 유형 선택, 비밀번호 암호화 | `POST /api/auth/signup` | REQ-001 |
| F-02 | 회원 | 로그인/로그아웃 | 세션 로그인, 로그아웃 시 세션 만료 | `POST /api/auth/login`, `/logout` | REQ-001 |
| F-03 | 회원 | 프로필 수정 | 닉네임·프로필 이미지 변경 | `PUT /api/auth/me` | REQ-002 |
| F-04 | 가게 | 가게 등록 | 가게 정보 입력 → 관리자 승인 대기 | `POST /api/stores` | REQ-003 |
| F-05 | 가게 | 가게 프로필 | 소개, 게시글/이벤트/정보 탭, 팔로워 수 | `GET /api/stores/{id}` | REQ-003 |
| F-06 | 피드 | 게시글 작성 | 이미지 업로드, 유형 선택, 해시태그 | `POST /api/files`, `POST /api/posts` | REQ-004 |
| F-07 | 피드 | 게시글 수정/삭제 | 작성자 본인만 가능 | `PUT/DELETE /api/posts/{id}` | REQ-004 |
| F-08 | 피드 | 메인 피드 | 전체/팔로우/우리동네/이벤트 탭, 더 보기 | `GET /api/posts?tab=` | REQ-005 |
| F-09 | 소통 | 좋아요 | 좋아요 토글(1인 1회) | `POST /api/posts/{id}/like` | REQ-006 |
| F-10 | 소통 | 댓글 | 댓글 작성·삭제 | `/api/posts/{id}/comments` | REQ-006 |
| F-11 | 소통 | 가게 팔로우 | 팔로우/언팔로우, 팔로우 피드 노출 | `POST /api/stores/{id}/follow` | REQ-007 |
| F-12 | 마케팅 | 이벤트 등록 | 이벤트 글 작성 시 기간·혜택·쿠폰 수량 입력 | `POST /api/posts` (type=EVENT) | REQ-008 |
| F-13 | 마케팅 | 쿠폰 받기/사용 | 1인 1매 다운로드, 매장 사용 처리, 기간 만료 | `POST /api/events/{id}/coupons`, `/api/coupons/{id}/use` | REQ-008 |
| F-14 | 마케팅 | 홍보 통계 | 조회수·좋아요·팔로워·쿠폰 사용률 | `GET /api/stores/{id}/stats` | REQ-008 |
| F-15 | 검색 | 통합 검색 | 가게·게시글·해시태그 검색 | `GET /api/search` | REQ-009 |
| F-16 | 관리 | 관리자 페이지 | 게시글 블라인드, 가게 승인/반려 | `/api/admin/**` | REQ-010 |
